# 0013: A safety floor for every game; age fit is separate
Status: Accepted
Date: 2026-11-20
## Context
The owner wants a family-safe platform that also hosts older games (for example an FPS), and asked whether every game can simply
be for all ages if the graphics are non-violent.
## Decision (recommended)
- **The floor (every game):** cartoon effects only, no harm, no gore, nothing frightening or mature, kit-only visuals, the word
  filter. This makes every game *safe* for any age.
- **Age fit (a tag, not a lock):** each game says who it suits (for example 3+, 7+, 10+) by difficulty, reading and complexity.
  Parents may filter by it; it is advice, not a safety wall.
## Consequences
Safety is enforced the same way for everyone. Games for older players are allowed as long as they meet the floor.
