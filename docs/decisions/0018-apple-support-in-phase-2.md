# 0018: Apple support is deferred to Phase 2
Status: Accepted
Date: 2026-11-20
## Context
Phase 1 is a closed beta (0017). The pad app was to ship on Android and iOS; iOS needs a Mac, an Apple developer account and
TestFlight (0016).
## Decision
- **Phase 1: Android only** for the pad app, installed as a file on family devices.
- **Phase 2: the iPad and iPhone app**, with the Apple developer account, TestFlight and App Store work.
- Pads are optional in every game, so most Phase 1 games need no phone at all.
## Consequences
- The Phase 1 plan drops the iOS shell, the Apple enrolment and the Mac. The time saved is a buffer for the pad game and
  Peekaboo Garden.
- iPhone owners in the beta cannot use the pad app. A browser page that joins by code (the fallback in 0006) is a possible
  stopgap, still to be decided.
- The Orlis Pro grip (an iPad mini class shell) is a Phase 2 item.
## Replaces
The iOS parts of 0001 and 0016.
