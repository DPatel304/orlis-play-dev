# 0003: The Orlis Box
Status: Accepted
Date: 2026-11-20
## Context
BACKLOG.md (Nov 16) said not to build our own console box for now because mini PC prices had doubled.
## Decision
The Orlis Box is an **off-the-shelf mini PC with a webcam and Orlis preinstalled**, sold to people who want to play and/or create
(the owner's "dev kit"). It is not custom hardware. Phase 1 uses the owner's laptop.
The hardware and operating system are chosen later, from measurements of 3D plus body tracking on candidate machines.
## Consequences
The kit's performance budgets are set by the weakest supported device (see the iPad floor in BACKLOG.md). Heat and fan noise
matter in a living room.
## Replaces
"Not building our own console box for now" (BACKLOG.md, The product).

## Update (2026-11-20)
Things to settle: Microsoft's rules for reselling PCs with software preinstalled (or a locked-down Linux image, which needs testing); re-checking mini PC prices; testing four tracked players on the candidate models; support, returns and fulfilment. The name "Dev Kit" in BACKLOG.md meant the Claude Code creation unlock; one of the two needs a new name.
