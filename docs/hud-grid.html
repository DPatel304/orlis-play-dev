The HUD grid: fixed anchors, flexible docks

Your invisible 20 by 11 grid stays. On top of it: a few fixed anchors that are in the same place in every game (so kids learn the screen once), and named docks where a game chooses what goes (so games can differ). A game asks for pieces by dock; the grid stacks and spaces them. Pieces come from one small set, in the kit's paper look.

The anchors and docks

Clock (fixed)Top centre, always. A game without a clock gives the cells back.
Hint words (fixed)Under the clock: a painted icon and at most four words. Arrive big, dock, fade.
Move card (fixed)Bottom left, 3 x 3. Slides in when a move is asked for, then away.
Goal (dock)Under the clock, the same width: one goal bar with three stars. No goal: the hint words move up into its row.
Corner (dock)Top left, 4 rows: score pills with each child's face (two to a row: one row for 1 to 2 players, two rows for 3 to 4), then chips and bars in the rows left.
Top right (dock)Badges, or one portrait: big (3 x 3) with a short notice while the character talks, small (2 x 2) when quiet.
Side rails (dock)The outside columns, 3 cells tall, with a gap above the move card: one tall meter each side.
Bottom rail (dock)The bottom row: one wide team bar, or the seekers' faces. Things read rarely, since hands are often here.
Badge (dock)Bottom right: one streak, combo or count, as wide as its contents.
Quiet when nothing changesDock pieces fade to 70% after 3 seconds without a change and pop back when they change (watch a score bump). Anchors never fade.
A 5% edgeEverything sits at least 5% in from the screen's edge, the usual safe margin for TVs.

How a game asks

hud(){ return {
  score: this.score,                                   // corner, first row (the shell draws these)
  goal: this.pile / 120,                               // the goal dock
  corner: [ { chip: 'crystal', value: this.crystals } ],
  left:   { meter: 'heart', fill: this.health, color: 'rose' },
  top:    { portrait: 'nova', notice: 'Follow the glow' },
  bottom: { bar: 'star', fill: this.xp, color: 'gold' },
  badge:  { icon: 'flame', value: this.streak }
}; }

No coordinates: the dock decides where and how big. A piece a game does not ask for is not drawn, and its cells go back to the game's world (and the keep-clear zones shrink with it).

Why this shape

  • Consistent where it matters: the clock, the hints and the move card never move, so a three-year-old finds them in every game.
  • Flexible where games differ: a story game needs health, a portrait and XP; a party game needs nothing. Docks give each a place without anyone drawing their own HUD.
  • Can't get messy: each dock has a cap (corner: scores plus 3 rows; top right: 1 portrait or 3 badges; one meter per rail; one bottom bar; one badge), pieces never overlap, and everything uses the same six piece types.
  • Easy for Create: a creator asks for "a heart meter on the left", never pixels, and the safety check can read it.
  • Changes from today: score pills become paper pills with the player's colour swatch (from the kit), chips use painted icons not emoji, and the docks for top right, the sides and the bottom row get built (they were planned, not built).
